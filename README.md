# På egna ben

En app för unga som flyttar hemifrån i Sverige. Under utveckling. Inget innehåll är granskat än.

- Instruktioner och regler: `CLAUDE.md` och `docs/`
- Testversion (utkast, ej granskat): https://tolgacelebi33.github.io/pa-egna-ben/

## Kommandon

```bash
npm install
npm run dev          # utvecklingsläge, visar utkast
npm test             # byggregler, katalog, sök, filter, kontrast
npm run build        # produktionsbygge, bara publicerat innehåll
npm run build:utkast # bygge med utkast, för test
npm run test:e2e     # webbläsartest mot utkastbygget på port 4323
```

Licenser för typsnitt och paket: `LICENSER.md`.
